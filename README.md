# CY뷰어 다운로드가 본 프로젝트로 통합되었습니다

소스 코드, 설치 파일, 아이폰 웹앱을 **[CY_Viewer](https://github.com/Kimmacaroni/CY_Viewer)**에서 함께 관리합니다.

- [Windows·macOS 설치 파일 및 이전 버전](https://github.com/Kimmacaroni/CY_Viewer/releases)
- [아이폰·아이패드 웹앱](https://kimmacaroni.github.io/CY_Viewer/)
- [사용 설명서](https://github.com/Kimmacaroni/CY_Viewer/blob/main/docs/USER_GUIDE.md)
- [오류 제보](https://github.com/Kimmacaroni/CY_Viewer/issues)

이 저장소는 기존 링크를 보존하기 위한 이전 안내로만 유지합니다.
새 릴리스는 본 프로젝트에 게시하며, 기존 배포 파일도 원본 그대로 이전했습니다.
아이폰 홈 화면 아이콘은 새 웹앱 주소에서 다시 추가해 주세요.
